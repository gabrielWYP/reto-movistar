# Checklist de evidencias

- [ ] Dataset y archivos utilizados están versionados.
- [ ] La demo parte desde un estado limpio.
- [ ] Health público responde correctamente.
- [ ] Cada dato crítico muestra su evidencia.

- [ ] La línea de auditoría contiene el journey completo.
- [ ] Las excepciones no ejecutan acciones financieras.
- [ ] Se registran latencia, errores y consumo de tokens.
- [ ] La demo fue repetida con un segundo caso sintético.
