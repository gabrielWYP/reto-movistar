# Datos del proyecto

Solo se permiten datos sintéticos o anonimizados autorizados. Los esquemas viven en `schemas/` y los ejemplos versionados en `synthetic/`.

## Prohibido

- Credenciales o secretos.
- Nombres, correos, teléfonos o documentos reales.
- Números reales de cuenta, tarjeta, factura o depósito.
- Exportaciones directas de sistemas corporativos.

Cada dataset debe documentar origen, generación, licencia, campos y limitaciones.
