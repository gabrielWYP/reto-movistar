# Área funcional - Cobranzas y Recaudo

Esta carpeta define intenciones de mensajes, datos de pago, reglas de conciliación y excepciones.

## Editar aquí

- `proceso.md`: flujo desde la comunicación hasta el cierre.
- `reglas.yaml`: condiciones de matching y revisión.
- `casos.csv`: mensajes ficticios con intención y resultado esperado.

No usar nombres, correos, teléfonos, cuentas o referencias bancarias reales.
