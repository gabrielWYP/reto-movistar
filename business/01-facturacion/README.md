# Área funcional - Facturación

Esta carpeta traduce el proceso PxQ y sus excepciones a reglas y casos verificables.

## Editar aquí

- `proceso.md`: pasos, actores, entradas, salidas y puntos de aprobación.
- `reglas.yaml`: reglas de negocio con severidad y evidencia requerida.
- `casos.csv`: ejemplos ficticios y resultado esperado.

Toda regla nueva debe incluir un caso que cumple, uno que falla y la evidencia que una persona usaría para decidir.
