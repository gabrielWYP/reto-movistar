# Agente de Cobranzas/Recaudación SON-IA  El agente es autónomo, pero está preparado para integrarse al Supervisor y al Agente BI a través de resultados JSON estables. Los saldos, vencimientos, ageing, prioridades y excepciones se calculan de manera determinística; la IA sólo selecciona herramientas y explica resultados respaldados por evidencia.  ## Estructura  ```text Agente Cobranzas/ ├── FRONT/       interfaz estática y contenedor Nginx ├── BACK/        API FastAPI, dominio, tools y pruebas ├── DEPLOY/      manifiestos para frontend y backend en pods separados ├── data/        ZIP de trabajo local (ignorado por Git) └── compose.yaml ejecución local con dos contenedores ```  En Kubernetes el frontend es el único componente expuesto. Nginx reenvía `/api` al servicio interno `collections-back`; el backend no requiere CORS público y recibe `OPENAI_API_KEY` exclusivamente como Secret.  ## Uso local  Para una experiencia simple en Windows, usa `Abrir Agente Cobranzas.vbs`. La primera ejecución instala las dependencias del backend y luego abre la interfaz local. Para simular la arquitectura de dos contenedores, con Docker Desktop ejecuta `docker compose up --build` dentro de esta carpeta y abre `http://127.0.0.1:8080`.  ## IA y costo  El backend usa el SDK oficial de OpenAI para la Responses API. No transmite el ZIP ni los CSV: sólo comparte con el modelo una pregunta y resultados compactos de tools. `gpt-5.6-terra` con razonamiento `low` es el valor predeterminado; puede ajustarse con variables de entorno sin modificar el código.
