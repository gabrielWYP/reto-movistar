# Área funcional - Demo y Calidad

Esta carpeta asegura que la solución pueda demostrarse, evaluarse y explicarse de forma repetible.

## Editar aquí

- `guion-demo.md`: recorrido y narrativa de la presentación.
- `criterios-aceptacion.yaml`: resultados observables del journey.
- `checklist-evidencias.md`: capturas, métricas y logs que deben conservarse.

La demo debe funcionar con un dataset nuevo además del caso usado durante el desarrollo.
