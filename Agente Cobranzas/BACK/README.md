# Backend - Agente de Cobranzas  API FastAPI independiente. Expone salud en `/health`, documentación en `/api/docs` y los endpoints determinísticos bajo `/api`.  El backend no contiene HTML ni sirve la interfaz en Kubernetes. El frontend Nginx se comunica por la red interna mediante el servicio `collections-back`.  `OPENAI_API_KEY` se inyecta como secreto de entorno. El SDK oficial se utiliza sólo para Responses API y function calling; los cálculos permanecen en código local.
