# Despliegue  `kubernetes/` contiene dos deployments: `collections-front` y `collections-back`. El backend se mantiene con una réplica porque la carga CSV es temporal y vive en memoria del proceso; para escalarlo se debe mover el dataset cargado a almacenamiento compartido o a un servicio de sesiones.  El PVC `collections-agent-data` debe contener el ZIP del reto en `source/SONIA_DESAFIO_03.zip`. El manifiesto `secret.example.yaml` es una plantilla: no debe aplicarse con una clave real ni versionarse con secretos.
